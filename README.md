# 随机题库答题系统

基于 Flask、SQLite 和原生 HTML/CSS/JavaScript 构建的随机题库练习系统。支持从 Excel 导入单选、多选和判断题，提供答题端与管理端，适用于本地运行或部署到 Linux 服务器。

## 功能概览

### 答题端

- 按章节随机抽取题目。
- 可分别设置单选题、多选题和判断题数量。
- 支持只练习错题或只练习收藏题。
- 提供按题型分组的题号导航，可跳转到指定题目。
- 可在答题过程中收藏题目；答题时不展示正确答案。
- 交卷后在独立结果页查看得分、作答情况、正确答案和解析。
- 刷新后恢复未完成练习；服务器端按账户和设备标识保存进度。错题、收藏、答题记录也按账户隔离。

### 管理端

- 按章节和题型筛选题目，并支持关键词搜索。
- 管理端拆分为概览、题库导入、题目管理和账户设置页面；题目管理支持分页浏览，避免一次性堆叠全部题目。
- 服务首次启动不会自动导入 Excel；管理员手动导入后，题目保存到 `question_bank.db`，后续启动直接加载数据库中的题目。
- 管理员可在“题库导入”页面一键清空全部题目；操作有二次确认，清空题目时会同步清理关联的错题和收藏，账户与答题记录仍保留。
- 管理员登录后新增、编辑、删除题目及批量上传 Excel；导入会校验题型、答案和选项并检测重复题，记录导入历史。
- 支持题库 JSON 备份与恢复、筛选后 CSV/JSON 导出、题目批量删除和批量修改章节。
- 概览展示学生数、答题人次、总答题题数和平均正确率，可查看学生统计并重置学生密码。
- 新数据库首次启动默认管理员账号为 `admin`，默认密码 `admin123`；可通过 `ADMIN_PASSWORD` 设置初始密码。已有管理员密码不会自动重置，可在管理端修改密码（新密码至少12位）。
- 修改题干、选项、正确答案、章节和解析。
- 管理题库内容；SQLite 保存共享题目及按账户隔离的答题记录、错题、收藏和进度。

### 判分规则

- 单选题和判断题按答案是否一致判定。
- 多选题必须所有正确选项均被选择，且没有选择错误选项，才计为正确。

## 技术栈

- 后端：Python、Flask、Waitress
- 数据库：SQLite
- Excel 读取：openpyxl
- 前端：HTML、CSS、原生 JavaScript

## 运行环境

- Python 3.10 或更新版本
- Windows 本地运行，或 Linux 服务器运行
- 安装依赖需要能够访问 Python 包索引

## 快速开始

### Windows

在项目目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

也可以按项目提供的 `start.bat` 启动。

启动后访问：

- 答题端：<http://127.0.0.1:5000/>
- 管理端：<http://127.0.0.1:5000/admin>

默认只监听本机地址，局域网或公网访问需要配置监听地址及网络防火墙。停止服务可在运行窗口按 `Ctrl+C`。

### Linux

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
PORT=8044 waitress-serve --listen=0.0.0.0:8044 app:app
```

访问 `http://服务器IP:8044/`。服务器运行建议使用 systemd 或其他进程管理器维持服务，并通过 Nginx 配置 HTTPS 与反向代理。

## Excel 题库格式

将 `.xlsx` 文件放入项目的 `已导入考试系统` 目录，再使用管理端提供的导入功能。题型由工作表名称识别：

| 工作表名称 | 题型 |
| --- | --- |
| `choice` | 单选题 |
| `mchoice` | 多选题 |
| `judgement` | 判断题 |

每张工作表的首行为列标题。导入器按字段标题读取题目数据；建议使用以下字段：

| 字段 | 用途 | 示例 |
| --- | --- | --- |
| `question` | 题干 | 以下哪项是……？ |
| `A`、`B`、`C`、`D`、`E` | 选项（适用于选择题） | 选项内容 |
| `answer` | 正确答案 | `B`；多选可填写多个选项字母 |
| `chapter` | 章节 | 第一章 |
| `analysis` | 答案解析 | 因为…… |

字段标题大小写可按导入器兼容规则处理。判断题若没有选项，系统提供“对/错”选项。不同来源的 Excel 表头可能不完全一致；导入后请在管理端抽查题目、选项、正确答案和解析是否正确。Word 文件不会由当前 Excel 导入流程处理。

## 答题端使用

1. 选择单选、多选、判断题数量；不需要的题型数量设为 `0`。
2. 可选择章节，或切换为错题练习、收藏题练习。
3. 点击开始练习后进入答题状态，使用题号导航或上一题/下一题切换题目。
4. 选择或取消选项，答题过程中页面不会显示标准答案。
5. 点击交卷后进入结果检查页查看判分和解析。

错题练习或收藏题练习的可抽题数量取决于当前已有的错题、收藏题；若题目不足，实际题量可能少于设置数量。

## 管理端使用

学生可在答题端注册账户（用户名3-32位字母、数字或下划线，密码至少6位）并登录。通过 `/admin` 打开管理端，使用管理员账户登录；学生账户不能访问题目管理和导入接口。管理员可选择章节、题型或输入关键词筛选题目，然后对题目进行新增、编辑或删除。修改题目时请核对正确答案格式：选择题答案应对应选项字母，判断题应与“对/错”选项一致，多选题填写完整的正确选项集合。

导入题库前建议备份数据库文件。导入后检查题目数及随机抽取结果，避免表头、答案格式或空单元格造成内容缺失。

## 答题进度与数据存储

应用使用项目目录下的 `question_bank.db` SQLite 数据库保存题库及答题相关数据。数据库文件由应用在首次启动时创建或初始化，不应提交到公开代码仓库。

未完成的练习同时使用浏览器本地存储和服务器端进度保存。服务器端进度按账户和设备标识隔离；清除浏览器站点数据或更换设备可能导致本地练习状态无法恢复。旧版本没有账户归属的错题、收藏、记录和进度会保留在 `legacy_*` 表中，不会自动分配给用户。数据库备份时应先停止应用，或使用 SQLite 支持的安全备份方式。

## 服务器部署

以下示例使用 Linux、Python 虚拟环境、Waitress 和 systemd。先生成并保存稳定密钥（不要提交到仓库）：

```bash
python3 -c 'import secrets; print(secrets.token_hex(32))'
sudo nano /etc/random-question-bank.env
```

环境文件内容（替换为生成的密钥；`ADMIN_PASSWORD` 仅新数据库首次初始化时使用）：

```text
FLASK_SECRET_KEY=替换为生成的随机密钥
ADMIN_PASSWORD=首次初始化管理员密码
COOKIE_SECURE=1
```

将环境文件限制为 root 可读，并在 systemd 服务单元中配置：

```ini
WorkingDirectory=/opt/random-question-bank
EnvironmentFile=/etc/random-question-bank.env
ExecStart=/opt/random-question-bank/.venv/bin/waitress-serve --listen=0.0.0.0:8044 app:app
```

修改服务配置后执行 `sudo systemctl daemon-reload` 并重启服务。确保 `FLASK_SECRET_KEY` 持久且重启后不变；不要只在 SSH shell 中临时 `export`。已有管理员账户会保留原密码，`ADMIN_PASSWORD` 不会重置它。

部署检查清单：

1. 确认依赖安装成功，应用进程保持运行。
2. 在服务器本机访问 `http://127.0.0.1:8044/` 和 `/api/stats`，确认返回正常。
3. 在云服务商安全组及系统防火墙中按需放行 TCP 8044；若通过 Nginx 代理，则只开放代理所需端口。
4. 从外部网络验证答题端可访问，并检查答题进度、答题记录和管理操作。
5. 设置数据库定期备份，并验证备份文件可恢复。

## 常见问题

### 页面无法访问

确认 Waitress 已启动并监听正确地址和端口；公网无法访问时，检查云安全组、系统防火墙、Nginx 配置和端口映射。

### 题目没有选项或答案异常

检查工作表名称、首行字段标题及单元格内容。重新导入后，在管理端抽查题干、选项、答案和解析。多选答案需准确表示完整选项集合。

### 刷新后进度没有恢复

确认浏览器没有清除站点数据，设备标识仍在；如使用服务器端恢复，检查服务端数据库是否可写以及请求是否成功。服务端进度按登录账户和设备标识匹配，不依赖客户端 IP。

### 管理端修改后数据未更新

确认管理操作成功，并检查运行中的服务使用的是预期项目目录和数据库文件；若同时存在多个应用进程，可能访问了不同实例或数据库。

## 安全说明

管理端已要求管理员登录；学生可自行注册。首次启动默认管理员账号为 `admin`、密码为 `admin123`，首次登录后应立即更换为强密码。`ADMIN_PASSWORD` 仅在首次初始化管理员账户时生效，不会覆盖已有账户密码。

生产部署必须在 systemd 等服务管理器中设置稳定且随机的 `FLASK_SECRET_KEY`，并在服务重启后保持不变，否则重启会使登录会话失效。配置 HTTPS 后设置 `COOKIE_SECURE=1`。错题、收藏、答题记录和进度按账户隔离；题库内容仍为共享数据，由管理员维护。正式对公网开放前，还应配置 HTTPS、防火墙、数据库备份，并避免将密码、令牌、生产数据库等敏感信息提交到 GitHub。
